# START_LEARN

> 8 周 Agent 学习与项目路线：面向数据 AI / 全球支付方向实习。

## 目标

在 8 周内完成从 SQL 与 Python 数据处理，到 RAG、工具调用和 Agent 工程实践的学习闭环，并沉淀两个可展示项目：

1. **支付数据指标分析与异常诊断**：使用 MySQL、Python 分析模拟支付交易数据。
2. **全球支付智能数据助手**：使用 RAG 与工具调用，实现规则问答和自然语言数据查询。

本计划不追求堆砌技术栈。优先建立 SQL、Python、数据分析、RAG、Agent 安全与项目交付能力；Spark、Flink、Kafka、多 Agent、模型微调等仅作了解。

## 学习投入与每日节奏

- 每周投入：22–25 小时。
- 工作日：19:00–19:40 LeetCode Hot100；19:50–21:20 学习/开发；21:30–22:00 提交代码与记录。
- 周六：5 小时深度开发。
- 周日：4 小时复盘、补缺和文档整理。
- 每晚 22:00：完成打卡，记录实际时长、产出、障碍和次日调整。

标记：**必** = 可以独立完成并解释；**知** = 了解适用场景即可。

## 项目一：支付数据指标分析与异常诊断

- 使用模拟支付、退款、拒付、商户与地区数据。
- 计算并解释 GMV、成功率、退款率、拒付率。
- 按地区、支付方式、商户维度进行下钻。
- 主动构造一个“成功率下降”案例并完成根因分析。

## 项目二：全球支付智能数据助手

用户可以提问：

- “什么情况下需要进行退款审核？”——通过 RAG 检索模拟规则，并给出引用。
- “上周东南亚信用卡支付成功率是否下降？”——Agent 生成安全的只读 SQL，查询后解释结果。

核心要求：RAG 引用来源、无证据拒答、只读 SQL、结构化输出、测试集评估、FastAPI 接口和 Docker 启动。
